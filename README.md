# Overtone

Overtone 0.3.1 добавляет Discord Rich Presence и тексты из LRCLIB в настольную Яндекс Музыку для Linux. В комплекте также есть нативный менеджер MPRIS и адаптер локальной замены аудио в mpv.

## Мод Яндекс Музыки

Поддерживается исходная настольная сборка **Яндекс Музыки 5.109.1 для Linux x86_64**. Откройте Overtone из меню приложений или выполните `overtone --launcher`. Нажмите «Установить и открыть», затем «Настройки мода» в боковом меню. Если клиент уже запущен отдельно, сначала закройте его. Путь к клиенту из нестандартной установки можно указать в `OVERTONE_YANDEX_EXECUTABLE`.

Overtone устанавливает мод в `resources/app.asar` установленной Яндекс Музыки. Перед заменой он создаёт и проверяет резервную копию `app.overtone-original.<хеш>.asar` рядом с архивом. После установки мод доступен из обычного ярлыка Яндекс Музыки, а лаунчер закрывается. Кнопка «Удалить мод» возвращает резервный архив. Для установки и восстановления закройте Яндекс Музыку. Если установлен другой мод, сначала восстановите исходный архив через его установщик. Настройки хранятся в `~/.config/overtone/yandex-mod.json`.

- **Discord RPC.** Откройте настольный Discord и включите «Показывать текущий трек» в настройках Overtone. Сборка использует общий Application ID и ассет `logo`. Выберите формат короткого статуса, язык подписей, обложку с названием альбома, ссылки, таймер паузы и интервал переподключения.
- **Тексты песен.** Доступны только Яндекс Музыка, только LRCLIB и оба порядка приоритета. Когда включён LRCLIB, для поиска отправляются название трека, исполнитель, альбом и длительность. При наличии синхронизированного текста он отображается построчно. При включении или выключении LRCLIB кнопка «Обновить окно» обновляет доступность текстов в интерфейсе плеера.

Метод работы со своим архивом основан на подходе [PulseSync Mod](https://github.com/PulseSync-LLC/PulseSync-mod). Настройки Discord ориентированы на [схему PulseSync](https://github.com/PulseSync-LLC/PulseSync-mod/blob/main/webModules/pulsesyncSettings/src/schema/sections/integrations.ts).

Замена аудио через менеджер MPRIS подтверждена для локальных записей в mpv 0.41.0. Встроенный FckCensor применяет свои пары ID внутри Яндекс Музыки.

## Быстрый запуск на Arch

```bash
sudo pacman -S --needed rust gtk4 pkgconf python
CARGO_BUILD_JOBS=1 cargo build --locked --release
./target/release/overtone --launcher
```

Для менеджера плееров выполните `overtone` или выберите «Менеджер плееров» в меню приложения. Для режима локального аудио нужны `mpv` и `mpv-mpris`. Нажмите «Запустить mpv с адаптером», при нескольких плеерах выберите новый экземпляр в списке, нажмите «Открыть локальную очередь» и выберите свои аудиофайлы. Плеер и фоновый процесс продолжают работу после закрытия менеджера. Кнопка «Выйти полностью» завершает приложение и его фоновые функции. Сам mpv можно закрыть отдельно, командой `overtone-ctl mpv-close` или кнопкой «Закрыть отдельный mpv» в обзоре.

### Повторить замену

1. Откройте в отдельном mpv локальную очередь из двух файлов A и C.
2. В обзоре нажмите «Заменить этот трек». Выберите файл B при помощи «Файл замены» и нажмите «Сохранить правило». Предпрослушивание подставляет B в текущую позицию.
3. Откройте A с C заново. Должен звучать B, а «Далее» должно включить C. Отключите правило и ещё раз запустите A. Должен звучать оригинал.
4. Для проверки без угадывания на слух запустите [smoke-тест](docs/integration.md) с разными тонами и захватом PCM.

Во временном режиме «Открыть другую версию» запрос `OpenUri` отправляется выбранному MPRIS-плееру. Этот режим может заменить очередь. Подтверждение появляется, когда плеер показывает нужный URI и состояние воспроизведения. Страница, открытая в браузере, сама по себе ничего не подтверждает.

## Плагины и обновления

Откройте вкладку «Плагины и обновления» в Overtone. Изменения применятся при следующем запуске Яндекс Музыки.

- **FckCensor** — адаптация для Overtone. Укажите пары ID записей, чтобы штатный плеер запрашивал аудио другой версии и возвращался к оригиналу при ошибке. Кнопка загрузки каталога импортирует названия, версии и обложки. [Исходный аддон](https://github.com/Hazzz895/FckCensor) · [Каталог](https://github.com/Hazzz895/FckCensorData)
- **YandexMusicTime** — локальный счётчик фактического воспроизведения с итогами за сегодня, неделю и всё время. [Исходный аддон](https://github.com/mak7im01/YandexMusicTime)
- **Custom Fonts** — выбор установленного на компьютере семейства шрифтов для Яндекс Музыки.
- **Яндекс Музыка напрямую** — отдельный локальный процесс стартует вместе с настольным клиентом Linux. Он привязывает HTTPS-соединения Музыки к физическому IPv4-интерфейсу. При отсутствии подходящего интерфейса или при настроенном прокси Chromium сохраняет системный маршрут. Активный режим виден в окне настроек мода. Имена разрешаются системным DNS, браузеры и другие приложения используют свои настройки. [Доменные правила для других клиентов](docs/vpn.md)
- **Обновления** — лаунчер автоматически проверяет стабильные релизы GitHub. Для установки в `~/.local` доступна автоустановка с проверкой SHA-256. Системный пакет обновляется через менеджер пакетов. [GitHub Releases](https://github.com/devodrag/overtone/releases)

## Установка для своего пользователя

Из корня проекта выполните эти команды, чтобы установить программу и ярлык в `~/.local`.

```bash
CARGO_BUILD_JOBS=1 cargo build --locked --release
python3 packaging/install.py --user --bin-dir target/release
```

## Пакет и сайт

```bash
mkdir -p release
PKGDEST="$PWD/release" CARGO_BUILD_JOBS=1 makepkg --clean
sudo pacman -U ./release/overtone-0.3.1-1-x86_64.pkg.tar.zst

python3 site/build.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Откройте [локальный сайт](http://127.0.0.1:8000/). Для размещения на обычном веб-сервере достаточно содержимого `dist`. Генератор подставляет из локального пакета имя, размер, версию и SHA‑256. Название, ID приложения и адреса проекта редактируются в `data/project.json`. Публичные релизы и обратная связь доступны в репозитории.

```bash
overtone --quit
sudo pacman -R overtone
```

Обычное удаление сохраняет настройки. Если включали автозапуск, сначала выключите его в настройках.

## Разработка

```bash
cargo fmt --all -- --check
CARGO_BUILD_JOBS=1 cargo clippy --locked --workspace --all-targets -- -D warnings
CARGO_BUILD_JOBS=1 cargo test --locked --workspace
dbus-run-session -- python3 tests/smoke.py target/release
```

- `overtone-core` хранит схему настроек, правила, приоритеты и модель таймера.
- `overtone-player` работает с MPRIS и отдельным mpv через приватный IPC.
- `overtone-background` владеет записью настроек, подписками и таймером. Команды передаются по Unix-сокету в закрытом каталоге `$XDG_RUNTIME_DIR/overtone`.
- `overtone` рисует GTK4-интерфейс. `overtone-ctl` позволяет выполнять те же действия из терминала и отдельно проверять MPRIS.

Управление GTK не входит в фоновый процесс. Настройки и правила находятся в `${XDG_CONFIG_HOME:-~/.config}/overtone/settings.json`, история и позиция мини-плеера в `${XDG_DATA_HOME:-~/.local/share}/overtone/`. Версия схемы настроек — 1.
