# Яндекс Музыка напрямую при включённом VPN

Правило по доменам действует на настольный клиент, браузер и другие приложения, трафик которых проходит через один VPN-клиент. Настройка выполняется в VPN-клиенте или маршрутизаторе. Overtone не меняет системную маршрутизацию.

Из каталога проекта сгенерируйте правило для нужного клиента.

| Клиент или ядро | Команда | Куда добавить |
| --- | --- | --- |
| Happ | `python3 integration/vpn/yandex_music.py happ-link` | Ссылка добавляет отдельный профиль маршрутизации. Для действующего профиля можно скопировать только `DirectSites` из вывода команды с форматом `happ`. |
| Xray | `python3 integration/vpn/yandex_music.py xray` | В `routing.rules` перед общим правилом отправки в VPN. Выход должен использовать протокол `freedom`. Если он называется иначе, укажите `--outbound`. |
| sing-box | `python3 integration/vpn/yandex_music.py sing-box` | В `route.rules` перед общим правилом отправки в VPN. Укажите имя имеющегося выхода типа `direct` через `--outbound`, если оно отличается. |
| Mihomo | `python3 integration/vpn/yandex_music.py mihomo` | Строки добавляются в действующий раздел `rules` до `MATCH` и других правил, подходящих для этих доменов. |
| VPN с исключениями по сайту | `python3 integration/vpn/yandex_music.py domains` | Добавьте точные хосты и суффиксы в список сайтов, идущих напрямую. Уточните в клиенте синтаксис для поддоменов. |

Список включает региональные адреса Музыки, API, Ynison, аудио, обложки и адреса входа. Часть CDN, статики и входа используется другими сервисами Яндекса, поэтому запросы к этим адресам тоже пойдут напрямую.

Happ может передавать серверный JSON в Xray без применения глобальных правил приложения. Для таких серверов добавляйте правило Xray непосредственно в JSON профиля. Обновление подписки может заменить серверный JSON. Для обычного профиля Happ используйте раздел маршрутизации. [Документация Happ](https://github.com/HappDev/happ_su/blob/main/dev-docs/examples-of-links-and-parameters.md) · [Формат профилей Happ](https://www.happ.su/main/dev-docs/routing)

Результат зависит от поддержки split tunneling. IP-исключения покрывают только найденные адреса и могут устаревать при изменениях CDN. Исключение по приложению направляет весь трафик выбранного приложения напрямую, а сайт в браузере требует отдельного правила. При обязательном VPN с запретом прямых соединений исключение должен разрешить владелец этой настройки. [Документация Amnezia](https://docs.amnezia.org/documentation/instructions/vpn-split-tunneling/)

Синтаксис ядер. [Xray](https://xtls.github.io/en/config/routing.html) · [sing-box](https://sing-box.sagernet.org/configuration/route/rule/) · [Mihomo](https://wiki.metacubex.one/en/config/rules/)
