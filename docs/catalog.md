# Каталог правил Overtone JSON v1

Подготовьте файл UTF‑8 с полями `schema: 1` и `rules`. Запись включает `from`, `to` и булево поле `enabled`. Значение `to: null` закрепляет оригинал. Действующее ручное правило, выключенное ручное правило и ручное исключение имеют приоритет над импортом по тому же оригиналу. Идентичность берётся из нормализованного URI или абсолютного пути, включая ID записи из ссылки Яндекс Музыки.

| Тип | Значение | Где применяется |
| --- | --- | --- |
| `local` | Абсолютный путь или URI `file://` | Адаптированный mpv |
| `yandex` | `https://music.yandex.ru/track/123` или ссылка вида `/album/…/track/…` | Сохранение правила и ручная попытка открытия через MPRIS |
| `audio` | Прямая ссылка HTTPS на доступный файл | mpv, экспериментально. Другие клиенты зависят от `OpenUri` и схемы |

[Пример JSON](catalog-example.json) содержит пример локальных путей. Замените их своими.

Импорт из файла или по HTTPS сначала показывает число принятых, пропущенных и конфликтующих записей. Дубликаты оригинала и пересечения с ручными правилами считаются конфликтами. Нераспознанные поля записи пропускаются. При ошибке формата, превышении 1 МиБ, ошибке сети и ответе без подходящих записей сохраняется кеш. Удалённый импорт принимает только сетевые источники. Для сетевого чтения задан лимит 8 секунд и выключены перенаправления. По расписанию каталог обновляется только после явной настройки интервала и HTTPS-адреса. Вместимость каталога и списка ручных правил ограничена 4096 записями каждый. Применение прекращается при обнаружении цикла. Для линейной цепочки берётся только первая замена.

FckCensorData не входит в поставку. В проверенной ревизии `list_v2` хранит `sources`, версии клиента, правки сущностей и `tracksStorages` с прямыми ссылками либо шаблонами. Поле `__fckCensor.audioSourceId` указывает запись каталога для копирования источника. Репозиторий не содержал отдельной лицензии на список или аудиофайлы, поэтому загрузка и преобразование его данных в Overtone пока недоступны. Условия кода FckCensor и условия на треки и графику проверяются отдельно.
